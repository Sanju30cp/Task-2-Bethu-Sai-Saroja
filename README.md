# Decode Labs - Task 2: Exploratory Data Analysis (EDA)
# Project Overview
This project was completed as part of **Decode Labs Task 2**. The objective was to perform **Exploratory Data Analysis (EDA)** on the provided e-commerce dataset to understand data patterns, trends, distributions, and derive meaningful business insights.
The analysis focused on:
* Understanding the structure of the dataset
* Identifying patterns and trends
* Analyzing numerical and categorical variables
* Calculating descriptive statistics
* Summarizing key findings using Excel-based analysis techniques

# Dataset Information
The dataset contains 1,200 e-commerce order records** with 14 attributes, including:
* OrderID – Unique order identifier
* Date – Order date
* CustomerID – Unique customer identifier
* Product – Product purchased
* Quantity – Number of items purchased
* UnitPrice – Price per item
* ShippingAddress – Delivery location
* PaymentMethod – Payment mode used
* OrderStatus – Current order status
* TrackingNumber – Shipment tracking ID
* ItemsInCart – Number of items in cart
* CouponCode – Applied discount coupon
* ReferralSource – Customer acquisition source
* TotalPrice – Total order value
